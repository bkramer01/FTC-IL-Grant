## Page documentation

`docs/` has one document per page of the site (start at `docs/README.md`). Whenever a change adds, removes or changes a feature on a page, update that page's document in the same commit, including its **Last updated** date and a line in its **Change history**. Add a new document, and a row in `docs/README.md`, for any new page.
